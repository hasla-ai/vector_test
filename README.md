# UCI Wine Quality 데이터셋 분석 및 파이썬 벡터 실습

제조 품질 데이터(UCI Wine Quality) 분석을 위한 표준 Python 프로젝트 개발 환경입니다.  
`uv`를 활용하여 의존성 관리를 표준화하고 이화학 데이터 기반의 벡터 노름 및 정규화 연산을 수행합니다.

## 🛠️ 개발 환경 및 기술 스택
- **Language**: Python >= 3.10
- **Package Manager**: [uv](https://github.com/astral-sh/uv)
- **Data & ML Libraries**: `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `ucimlrepo`

1장 1강: 벡터·노름·정규화 (1)

 - 제조 품질: 와인 샘플별 이화학 측정값(산도, 당도, 알코올 등)을 특성 벡터로 보고 노름과 정규화를 계산합니다.

필수 1. 품질 측정 기록을 벡터로 다루기

 - 와인 제조사 품질관리팀은 생산 샘플마다 산도·당도·알코올 같은 이화학 값을 여러 개 측정해 기록합니다. 값이 여러 개이므로 샘플 하나를 숫자 하나로는 표현할 수 없고, "측정값 묶음" 단위로 다뤄야 합니다. 먼저 이 기록이 스칼라·벡터·행렬 중 무엇에 해당하는지 정리하고, 샘플 간 비교에 필요한 기본 연산을 익힙니다. 

문제 1-1 스칼라. 벡터. 행렬의 구분

**요구 사항**

1. `X`에서 첫 번째 샘플의 측정값을 `v1`(NumPy 배열)로 추출합니다.
2. `X` 전체 표, `v1`, `v1`의 첫 번째 원소를 각각 출력하고 `shape`(또는 값)을 확인합니다.
3. 세 대상이 각각 행렬·벡터·스칼라 중 무엇인지, 분석에서 어떤 역할을 하는지 한 문장씩 설명합니다.

**출력 결과**
  - 데이터 행렬의 shape과 특성 벡터의 shape
  - 스칼라 값 1개
  - 세 대상의 역할 구분 설명

```bash
=== [1장-1강-필수1] 문제 1-1 출력 결과 ===
1. 전체 데이터 표 (행렬, X) shape: (6497, 11)
2. 첫 번째 샘플 (특성 벡터, v1) shape: (11,)
3. v1의 첫 번째 원소 (스칼라, s1) 값: 7.4 (특성명: fixed_acidity)

=== [세 대상의 역할 구분 설명] ===
1. 데이터 행렬 (X): 전체 와인 샘플과 이화학 측정값을 통합 관리하는 2차원 공간입니다.
2. 특성 벡터 (v1): 와인 1개 샘플의 다차원 이화학 측정값 묶음으로, 데이터 공간에서 개별 와인의 위치를 정의합니다.
3. 스칼라 (s1): 산도(fixed_acidity)와 같은 단일 항목 수치로, 특성 벡터를 구성하는 개별 속성값입니다.
```
- X는 행이 샘플, 열이 측정 항목인 2차원 행렬로, 여러 샘플을 한 번에 비교할 때 사용합니다.
- v1은 샘플 하나의 측정값을 순서대로 담은 1차원 벡터로, 샘플 한 건의 특성을 표현합니다.
- alcohol은 값 하나만 가지는 스칼라로, 단일 항목의 크기만 나타냅니다.

문제 1-2 : 벡터의 덧셈과 스칼라 곱 계산하기

**요구 사항**

1. 두 번째 샘플의 측정값을 `v2`로 추출합니다.
2. 두 샘플의 평균 측정값을 `(v1 + v2) * 0.5`로 계산합니다. (벡터 덧셈 + 스칼라 곱)
3. `v1`의 각 성분을 2배로 키운 `2 * v1`을 계산하고, 원본과 비교합니다.
4. 벡터 덧셈과 스칼라 곱이 각각 어떤 의미를 갖는지 한 문장씩 설명합니다.

- **출력 결과**
    - 두 샘플의 평균 벡터
    - 스칼라 곱 결과와 원본 비교
    - 두 연산의 의미 설명

```bash
=== [1장-1강-필수1] 문제 1-2 출력 결과 ===
1. 두 샘플의 평균 벡터 (v_mean):
[ 7.6   0.79  0.    2.25  0.09 18.   50.5   1.    3.36  0.62  9.6 ]

2. 스칼라 곱 결과 (2 * v1)와 원본 (v1) 비교:
   - 원본 v1 (상위 3개): [7.4 0.7 0. ]
   - 2 * v1  (상위 3개): [14.8  1.4  0. ]

=== [두 연산의 의미 설명] ===
1. 벡터 덧셈: 여러 샘플의 동일한 측정 항목들을 요소별(Element-wise)로 합산하여, 데이터 합성이나 전체적인 특성 총량을 계산하는 역할을 합니다.
2. 스칼라 곱: 벡터의 방향(성분 간 비율)은 유지한 채 전체적인 크기(스케일)만 조절하여, 가중치 부여나 단위 변환 및 비율 조정을 수행하는 역할을 합니다.
```

필수 2 : 샘플별 측정값의 "크기"를 하나의 숫자로 요약하기

- 품질관리팀은 샘플마다 측정 항목이 10개가 넘어 한눈에 비교하기 어렵습니다. 각 샘플의 측정값 묶음이 전체적으로 얼마나 큰지를 숫자 하나로 요약할 수 있으면 이상 샘플을 빠르게 걸러낼 수 있습니다. 노름을 계산해 벡터의 크기를 재고, 크기 차이를 없앤 뒤 방향만 비교할 수 있도록 정규화합니다.

문제 2-1 L1·L2·L∞ 노름 계산하기
  - **요구 사항**

1. `v1`에 대해 L1 노름, L2 노름, L∞ 노름을 각각 계산합니다.
2. L2 노름은 `np.sqrt(np.sum(v1 ** 2))`로도 직접 계산해 `np.linalg.norm(v1, 2)`와 값이 같은지 확인합니다.
3. 세 노름이 각각 무엇을 크게 반영하는지 비교해 한 문장으로 설명합니다.

- **출력 결과**
    - L1, L2, L∞ 노름 값
    - 직접 계산한 L2와 라이브러리 결과 일치 여부
    - 세 노름의 차이 설명

```bash
=== [1장-1강-필수2] 문제 2-1 출력 결과 ===
1. L1 노름 (L1 Norm)   : 69.5438
2. L2 노름 (L2 Norm)   : 37.9191 (직접 계산: 37.9191, 일치 여부: True)
3. L∞ 노름 (L∞ Norm)   : 34.0000

=== [세 노름의 특징 비교 설명] ===
L1 노름은 모든 성분의 절대값 합으로 전체적인 스케일의 총량을 평등하게 반영하고, L2 노름은 제곱합의 제곱근으로 기하학적 직선 거리를 반영하며, L∞ 노름은 성분 중 가장 큰 최대 절대값을 집중적으로 반영합니다.
```
- L1은 성분의 절댓값을 모두 더하므로 **작은 값들의 누적**까지 반영합니다.
- L2는 제곱해서 더하므로 **큰 성분의 영향이 커지고**, 피타고라스 정리를 확장한 유클리드 거리와 같은 값입니다.
- L∞는 **가장 큰 성분 하나**만 보므로, 특정 항목이 튀는 샘플을 잡아낼 때 유용합니다.




## 2. 다음 단계 실습 방향 (제조 품질 데이터 EDA 및 모델링)

환경 구축과 기본 벡터 연산 실습이 완료되었으므로, 본격적인 제조 품질 데이터 분석 단계로 나아갈 수 있습니다.

### 추천 다음 단계

1. **이화학 데이터 탐색적 데이터 분석 (EDA)**
